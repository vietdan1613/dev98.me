`useId` is a React Hook that generates a unique, stable ID for each component instance. It is especially useful for connecting form inputs with labels, hints, and accessibility attributes.

### 1. The Problem: Duplicate IDs

HTML labels use `htmlFor` and `id` to associate a label with an input.

```jsx
function TextField() {
  return (
    <>
      <label htmlFor="email">Email</label>
      <input id="email" />
    </>
  );
}
```

This works for one instance, but rendering the component multiple times creates duplicate IDs.

```jsx
<TextField />
<TextField />
```

Duplicate IDs violate HTML requirements and can cause labels and accessibility relationships to target the wrong element.

### 2. The Solution: `useId`

Use `useId` to generate an ID for each component instance.

```jsx
import { useId } from "react";

function TextField({ label, hint }) {
  const id = useId();
  const hintId = `${id}-hint`;

  return (
    <div>
      <label htmlFor={id}>{label}</label>
      <input id={id} aria-describedby={hintId} />
      <p id={hintId}>{hint}</p>
    </div>
  );
}
```

Now each instance has its own ID, and `aria-describedby` connects the input to its corresponding hint.

```jsx
<TextField label="Email" hint="Enter your email address." />
<TextField label="Password" hint="Use a strong password." />
```

React generates IDs that remain stable across re-renders and supports consistent IDs between server rendering and client hydration when the component trees match.

### 3. When Not to Use `useId`

`useId` is designed for accessibility-related DOM relationships, not general-purpose identifiers.

- **List keys:** Use stable data IDs.
- **Database IDs:** Generate identifiers through your data layer.
- **Random values:** Use an appropriate random or unique ID generator when needed.

```jsx
// ❌ Incorrect
items.map(() => <Row key={useId()} />);

// ✅ Correct
items.map((item) => <Row key={item.id} />);
```

Hooks must be called at the top level of a component or custom Hook, not inside loops or callbacks.
