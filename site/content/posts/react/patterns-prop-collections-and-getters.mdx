Prop Collections and Prop Getters help reusable hooks expose interaction logic through flexible, accessible APIs.

### 1. Problem: Repetitive Wiring

A reusable hook may require consumers to manually connect state, event handlers, and accessibility attributes.

```tsx
<button
  aria-pressed={on}
  onClick={toggle}
>
  Toggle
</button>
```

As the component grows, consumers must remember to wire every required prop correctly.

### 2. Prop Collections

A **prop collection** is a ready-made props object returned by a hook.

```tsx
function useCounter() {
  const [count, setCount] = useState(0);

  return {
    count,
    counterProps: {
      children: count,
      onClick: () => setCount(c => c + 1),
    },
  };
}
```

Usage:

```tsx
const { counterProps } = useCounter();

<button {...counterProps} />;
```

**Advantages:** Simple and convenient for common use cases.

**Limitation:** Customizing individual props or event handlers can be awkward.

### 3. Prop Getters

A **prop getter** is a function that generates props while allowing consumers to supply custom values and handlers.

```tsx
function useToggle() {
  const [on, setOn] = useState(false);

  const toggle = () => setOn(value => !value);

  function getTogglerProps({
    onClick,
    ...props
  }: React.ComponentPropsWithoutRef<"button"> = {}) {
    return {
      ...props,
      "aria-pressed": on,
      onClick: (event: React.MouseEvent<HTMLButtonElement>) => {
        onClick?.(event);

        if (!event.defaultPrevented) {
          toggle();
        }
      },
    };
  }

  return { on, getTogglerProps };
}
```

Usage:

```tsx
const { getTogglerProps } = useToggle();

<button
  {...getTogglerProps({
    onClick: () => console.log("Custom logic"),
    className: "toggle-button",
  })}
>
  Toggle
</button>;
```

The getter combines the consumer's custom props with the hook's internal behavior.

- **Custom logic:** The consumer's click handler runs first.
- **Default prevention:** Calling `event.preventDefault()` prevents the toggle.
- **Accessibility:** The hook supplies the current `aria-pressed` value.

The order of prop spreading is intentional: internal `aria-pressed` and `onClick` behavior take precedence over conflicting consumer props.
