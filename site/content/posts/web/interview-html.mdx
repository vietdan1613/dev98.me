# HTML

### 1. What are semantic HTML elements, and why are they important?

> Semantic HTML elements clearly describe their meaning in a human- and machine-readable way.
> - Examples `<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, and `<footer>`.

> How do semantic elements improve accessibility?
> - Screen readers can better understand the structure and purpose of content.

> What is the difference between inline, inline-block, and block?
> - Inline: not start on a new line. Block elements start on a new line. Inline-block elements are similar to inline but allow setting width and height
