# Python Fundamentual 

## 1. What is Python?

**Keywords:** `Readable` · `Interpreted` · `Dynamic Typing` · `Libraries` · `Cross-platform`

**Expectations:** Define Python as a high-level programming language, and mention its readable syntax, dynamic typing, large ecosystem, and cross-platform support.

---

## 2. List vs Tuple

**Keywords:** `Mutable` · `Immutable` · `Memory` · `Performance`

**Expectations:** Contrast a **list**, which is mutable so its elements can be changed, with a **tuple**, which is immutable. Point out that tuples use less memory and are generally faster to iterate.

---

## 3. What is `__init__()`?

**Keywords:** `Constructor` · `Initialize` · `Object`

**Expectations:** Explain that `__init__()` is called when an object is created and is mainly used to initialize the object's state and properties.

---

## 4. Mutable vs Immutable

**Keywords:** `Mutable = Change` · `Immutable = Cannot Change`

**Expectations:** Explain that mutable objects can be modified after creation while immutable objects cannot be changed. Name `list`, `dict`, and `set` as mutable examples, and `string`, `tuple`, and numbers as immutable ones.

---

## 5. What is Comprehension?

**Keywords:** `One-line` · `List` · `Dictionary` · `Generator`

**Expectations:** Define a comprehension as a concise way to create collections from an iterable, and mention that list and dictionary comprehensions are common. Point out that `(x for x in ...)` creates a generator expression.

```python
squares = [x ** 2 for x in range(5)]
```

---

## 6. What is the GIL?

**Keywords:** `CPython` · `One Thread` · `CPU-bound` · `I/O-bound`

**Expectations:** Explain that in CPython the Global Interpreter Lock allows only one native thread to execute Python bytecode at a time. Point out that this limits multithreading for CPU-bound tasks but works well for I/O-bound operations.

---

# Intermediate & Advanced Python

## 7. Common Searching and Graph Algorithms

**Keywords:** `Binary Search` · `BFS` · `DFS` · `A*` · `AVL`

**Expectations:** Name each algorithm with its purpose: **Binary Search** searches sorted data efficiently, **BFS** traverses level by level and is useful for shortest paths, and **DFS** explores deeply before backtracking. Also mention **A*** for pathfinding using heuristics and **AVL** as a self-balancing search tree.

---

## 8. What is a `KeyError`?

**Keywords:** `Missing Key` · `.get()` · `try/except` · `in`

**Expectations:** Explain that a `KeyError` occurs when accessing a dictionary key that does not exist. Name the common fixes: use `.get()`, wrap the access in `try/except`, or check `if key in data` first.

```python
data.get("name")
```

---

## 9. How Does Python Manage Memory?

**Keywords:** `Private Heap` · `Reference Counting` · `Garbage Collection`

**Expectations:** Explain that Python manages memory automatically using a private heap, and mention that reference counting and garbage collection remove objects that are no longer needed.

---

## 10. Shallow Copy vs Deep Copy

**Keywords:** `Reference` · `Nested Objects` · `Independent Copy`

**Expectations:** Contrast a **shallow copy**, which creates a new outer object but keeps references to nested objects, with a **deep copy**, which recursively copies nested objects to create a fully independent structure.

---

## 11. What is the `collections` Module?

**Keywords:** `Counter` · `defaultdict` · `deque` · `OrderedDict`

**Expectations:** Explain that the `collections` module provides specialized data structures. Give examples such as `Counter` for counting elements and `defaultdict` for simplifying dictionary initialization.

```python
from collections import Counter

Counter(["a", "b", "a"])
```

---

## 12. What is Monkey Patching?

**Keywords:** `Runtime` · `Modify Behavior` · `Class` · `Module`

**Expectations:** Define monkey patching as changing or replacing the behavior of a class or module at runtime. Mention that it can be useful in testing, but point out that excessive use makes code harder to understand.

---

## 13. What is the `with` Statement?

**Keywords:** `Resource Management` · `Cleanup` · `File`

**Expectations:** Explain that the `with` statement manages resources automatically and ensures cleanup. Give the file example and point out that the file is closed automatically after the block.

```python
with open("file.txt") as file:
    data = file.read()
```

---

## 14. Why Use `else` with `try/except`?

**Keywords:** `No Exception` · `Success`

**Expectations:** Explain that the `else` block runs only when the `try` block completes without an exception.

```python
try:
    result = 10 / 2
except:
    print("Error")
else:
    print("Success")
```

## 15. What are Decorators?

**Keywords:** `Wrapper` · `Extend Behavior` · `@decorator`

**Expectations:** Explain that a decorator adds behavior to an existing function without modifying the function itself. Mention common uses such as logging, authentication, caching, and timing.

```python
@my_decorator
def hello():
    print("Hello")
```

## 16. What are Context Managers?

**Keywords:** `__enter__` · `__exit__` · `with` · `Resource`

**Expectations:** Explain that context managers control how resources are acquired and released. Walk through how the `with` statement calls `__enter__()` when entering the block and `__exit__()` when leaving it.

## 17. What are Metaclasses?
