Python fundamentals are the building blocks of every Python application. Understanding variables, data types, operators, control flow, and object behavior helps you write clean, predictable, and maintainable code.

### 1. Variables and Data Types

Variables store references to objects. Python uses dynamic typing, so you don't need to declare a variable's type explicitly.

```python
name = "Alice"
age = 25
height = 1.68
is_developer = True

skills = ["Python", "FastAPI"]
coordinates = (10.5, 20.3)
unique_ids = {1, 2, 3}
user = {"name": "Alice", "age": 25}
```

Common built-in data types include:

- `int`: integers, such as `10`
- `float`: decimal numbers, such as `3.14`
- `str`: text, such as `"Hello"`
- `bool`: Boolean values, `True` and `False`
- `list`: ordered, mutable collections
- `tuple`: ordered, immutable collections
- `set`: collections of unique elements
- `dict`: key-value mappings
- `NoneType`: the type of `None`, representing the absence of a value

Use `type()` to inspect an object's type and `isinstance()` to check whether an object belongs to a particular type.

```python
value = 42

print(type(value))                 # <class 'int'>
print(isinstance(value, int))      # True
```

### 2. Strings and String Formatting

Strings represent text and support operations such as concatenation, indexing, slicing, and formatting.

```python
first_name = "Alice"
last_name = "Smith"

full_name = first_name + " " + last_name

print(full_name)       # Alice Smith
print(full_name[0])    # A
print(full_name[:5])   # Alice
```

Use f-strings to embed expressions directly into strings.

```python
name = "Alice"
age = 25

message = f"{name} is {age} years old."
print(message)
```

### 3. Operators and Expressions

Operators perform calculations, comparisons, and logical operations.

**Arithmetic operators**

```python
a, b = 10, 3

print(a + b)   # 13
print(a - b)   # 7
print(a * b)   # 30
print(a / b)   # 3.333...
print(a // b)  # 3
print(a % b)   # 1
print(a ** b)  # 1000
```

**Comparison and logical operators**

```python
age = 25

print(age >= 18)                     # True
print(age == 25)                     # True
print(age != 20)                     # True
print(age >= 18 and age < 60)        # True
print(age < 18 or age >= 65)         # False
print(not False)                     # True
```

Python also provides assignment operators (`+=`, `-=`, `*=`), membership operators (`in`, `not in`), and identity operators (`is`, `is not`).

### 4. Conditional Statements

Conditional statements execute different code depending on whether a condition is satisfied.

```python
score = 85

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "F"

print(grade)  # B
```

Python uses indentation to define code blocks instead of curly braces. For simple conditional assignments, a conditional expression can be useful:

```python
status = "adult" if age >= 18 else "minor"
```

### 5. Loops and Iteration

Loops allow you to execute code repeatedly. **For loops** iterate over items in an iterable.

```python
languages = ["Python", "JavaScript", "Go"]

for language in languages:
    print(language)
```

Use `range()` when you need a sequence of numbers.

```python
for number in range(1, 4):
    print(number)
```

**While loops** continue executing while a condition remains true.

```python
count = 0

while count < 3:
    print(count)
    count += 1
```

Two important control statements are:

- `break`: exits the nearest enclosing loop.
- `continue`: skips the remainder of the current iteration.

### 6. Input and Output

Use `input()` to read user input and `print()` to display output.

```python
name = input("Enter your name: ")
print(f"Hello, {name}!")
```

An important detail: `input()` always returns a string. Convert the value when you need a number.

```python
age = int(input("Enter your age: "))
print(f"Next year, you will be {age + 1}.")
```

For file output, use `open()` with a context manager to ensure the file is properly closed.

```python
with open("output.txt", "w", encoding="utf-8") as file:
    file.write("Hello, Python!")
```

### 7. Type Conversion

Type conversion transforms a value from one type to another.

```python
age = int("25")
price = float("19.99")
message = str(100)

print(age + 5)       # 30
print(price)         # 19.99
print(message)       # 100
```

Some conversions can fail if the input is invalid.

```python
number = int("abc")  # ValueError
```

When converting external input, handle possible errors appropriately.

```python
try:
    number = int(input("Enter a number: "))
except ValueError:
    print("Please enter a valid integer.")
```

### 8. Truthy and Falsy Values

Python evaluates values in Boolean contexts, such as `if` statements and `while` loops. Falsy values include:

- `False`
- `None`
- Numeric zero, including `0` and `0.0`
- Empty strings and collections, such as `""`, `[]`, `{}`, and `set()`

Most other objects are truthy.

```python
items = []

if items:
    print("Items exist")
else:
    print("The list is empty")
```

A common pattern is to use `or` to provide a default value:

```python
username = input("Username: ").strip() or "Guest"
```

Be careful: `or` also replaces valid falsy values such as `0`. When only `None` should trigger a default, use an explicit check:

```python
quantity = 0
quantity = 10 if quantity is None else quantity
```

### 9. Identity vs Equality: `is` vs `==`

These operators serve different purposes.

- `==` checks whether two objects have equal values.
- `is` checks whether two references point to the same object.

```python
a = [1, 2, 3]
b = [1, 2, 3]
c = a

print(a == b)  # True
print(a is b)  # False
print(a is c)  # True
```

Although `a` and `b` contain equal lists, they are separate objects.

Use `is` for identity checks, particularly when checking against `None`.

```python
result = None

if result is None:
    print("No result available")
```

### 10. Mutable vs Immutable Objects

Objects differ in whether their contents can change after creation.

**Mutable objects** can be modified in place. Common examples include lists, dictionaries, and sets.

**Immutable objects** cannot be modified after creation. Examples include integers, floats, Booleans, strings, and tuples. A tuple can still contain references to mutable objects.

```python
# Mutable object
numbers = [1, 2, 3]
numbers.append(4)

print(numbers)  # [1, 2, 3, 4]

# Immutable object
name = "Alice"
name = name + " Smith"

print(name)     # Alice Smith
```

The second example creates a new string and reassigns the variable. Assignment does not automatically copy an object. Multiple variables can reference the same mutable object.

```python
original = [1, 2, 3]
alias = original

alias.append(4)

print(original)  # [1, 2, 3, 4]
```

If you need an independent shallow copy of a list, use `copy()`:

```python
original = [1, 2, 3]
copied = original.copy()

copied.append(4)

print(original)  # [1, 2, 3]
print(copied)    # [1, 2, 3, 4]
```

A shallow copy does not recursively copy nested mutable objects. Use `copy.deepcopy()` when an independent copy of nested structures is required.
