Functions are fundamental to writing reusable, maintainable Python code. They allow you to encapsulate logic, accept inputs, return results, and build complex applications from smaller components.

### 1. Functions and Parameters

A function is a reusable block of code defined using the `def` keyword. It can accept parameters and return a result.

```python
def calculate_total(price, quantity):
    return price * quantity

total = calculate_total(100, 3)
print(total)  # 300
```

Here, `price` and `quantity` are parameters, while `100` and `3` are arguments passed to the function.

Python supports several parameter types:

```python
def create_user(name, role="user"):
    return {"name": name, "role": role}

print(create_user("Alice"))
# {'name': 'Alice', 'role': 'user'}

print(create_user("Bob", role="admin"))
# {'name': 'Bob', 'role': 'admin'}
```

Parameters can be required or optional through default values. Python also supports positional-only parameters, keyword-only parameters, and variable-length arguments.

A function without an explicit `return` statement returns `None`.

### 2. `*args` and `**kwargs`

Python allows functions to accept a variable number of arguments.

- `*args` collects additional positional arguments into a tuple.
- `**kwargs` collects additional keyword arguments into a dictionary.

```python
def calculate_sum(*args):
    return sum(args)

print(calculate_sum(1, 2, 3, 4))  # 10
```

A function can accept both forms:

```python
def create_user(*args, **kwargs):
    print("Positional:", args)
    print("Keyword:", kwargs)

create_user("Alice", 25, role="admin", active=True)
```

Output:

```text
Positional: ('Alice', 25)
Keyword: {'role': 'admin', 'active': True}
```

The same syntax can unpack existing collections when calling functions:

```python
def add(a, b):
    return a + b

numbers = (3, 5)
options = {"a": 3, "b": 5}

print(add(*numbers))   # 8
print(add(**options))  # 8
```

### 3. Variable Scope and the LEGB Rule

Python determines where a variable can be accessed using the LEGB rule:

1. **Local:** Variables defined inside the current function.
2. **Enclosing:** Variables in an enclosing function.
3. **Global:** Variables defined at the module level.
4. **Built-in:** Names provided by Python, such as `len()` and `print()`.

```python
message = "global"

def outer():
    message = "enclosing"

    def inner():
        message = "local"
        print(message)

    inner()

outer()  # local
```

Python resolves the name `message` from the nearest applicable scope.

Use `global` to reassign a module-level variable and `nonlocal` to reassign a variable in an enclosing function.

```python
count = 0

def increment():
    global count
    count += 1

increment()
print(count)  # 1
```

However, relying heavily on global state can make code harder to test and maintain. Returning values or passing dependencies explicitly is often preferable.

### 4. Closures

A closure occurs when an inner function retains access to variables from its enclosing function, even after the enclosing function has finished executing.

```python
def make_multiplier(factor):
    def multiply(number):
        return number * factor

    return multiply

double = make_multiplier(2)
triple = make_multiplier(3)

print(double(5))  # 10
print(triple(5))  # 15
```

The returned functions retain access to their respective `factor` values.

Closures are useful for creating configurable functions, callbacks, and lightweight function factories.

To modify an enclosing variable, use `nonlocal`:

```python
def make_counter():
    count = 0

    def increment():
        nonlocal count
        count += 1
        return count

    return increment

counter = make_counter()

print(counter())  # 1
print(counter())  # 2
```

### 5. Lambda Functions

A lambda function is a small anonymous function defined with the `lambda` keyword. Its body contains a single expression, whose result is returned automatically.

```python
square = lambda number: number ** 2

print(square(5))  # 25
```

Lambda functions are commonly used for short operations passed to other functions.

```python
users = [
    {"name": "Alice", "age": 30},
    {"name": "Bob", "age": 20},
    {"name": "Charlie", "age": 25},
]

users.sort(key=lambda user: user["age"])

print([user["name"] for user in users])
# ['Bob', 'Charlie', 'Alice']
```

For complex logic, use a regular `def` function because it supports multiple statements, documentation, and more descriptive naming.

### 6. Higher-Order Functions

A higher-order function accepts another function as an argument, returns a function, or does both.

Because functions are first-class objects in Python, they can be assigned to variables and passed around like other values.

```python
def apply_operation(operation, value):
    return operation(value)

def square(number):
    return number ** 2

print(apply_operation(square, 4))  # 16
```

A function can also return another function:

```python
def get_operation(operation):
    if operation == "square":
        return lambda x: x ** 2

    return lambda x: x

calculate = get_operation("square")
print(calculate(5))  # 25
```

Higher-order functions are useful for callbacks, reusable transformations, decorators, and configurable behavior.

### 7. Type Hints

Type hints document the expected types of function parameters and return values. They improve readability, editor support, and static analysis.

```python
def calculate_total(price: float, quantity: int) -> float:
    return price * quantity
```

Python does not normally enforce these annotations at runtime. Tools such as mypy and Pyright can check them statically.

Use collection types to describe structured inputs:

```python
def get_names(users: list[dict[str, str]]) -> list[str]:
    return [user["name"] for user in users]
```

For more flexible types, use `Optional`, `Union`, or their modern alternatives.

```python
def find_user(user_id: int) -> str | None:
    if user_id == 1:
        return "Alice"

    return None
```

The `str | None` annotation means the function can return either a string or `None` in Python 3.10 and later.

Type hints can also describe callbacks with `Callable` and generator return types with `Generator`.

### 8. Generators and `yield`

A generator produces values lazily, one at a time, rather than building the entire result in memory.

A generator function uses `yield` to produce a value and suspend its execution. When iteration resumes, execution continues from where it stopped.

```python
def count_up_to(limit):
    number = 1

    while number <= limit:
        yield number
        number += 1

for number in count_up_to(3):
    print(number)
```

Output:

```text
1
2
3
```

Calling `count_up_to(3)` returns a generator object. The function body begins executing when the generator is iterated, not when it is created.

Generators are useful for processing large files, streaming API responses, and handling data that does not need to be stored all at once.

```python
def read_numbers():
    for number in range(1_000_000):
        yield number

numbers = read_numbers()

print(next(numbers))  # 0
print(next(numbers))  # 1
```

Unlike a regular function that returns a complete list, a generator retains its execution state and produces values on demand.
