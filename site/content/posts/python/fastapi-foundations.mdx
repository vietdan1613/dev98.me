FastAPI is a modern Python framework for building APIs. It's fast, easy to learn, and comes with built-in support for request validation, automatic API documentation, and dependency injection.

### Project structure

```
fastapi-app/
├── app/
│   ├── __init__.py
│   ├── main.py
│   ├── database.py
│   ├── models.py
│   ├── schemas.py
│   ├── services.py
│   └── routers/
│       ├── __init__.py
│       └── products.py
└── requirements.txt
```

### 1. Install dependencies

`requirements.txt`

```
fastapi
uvicorn[standard]
sqlalchemy
```

Install and run:

```
pip install -r requirements.txt
uvicorn app.main:app --reload
```

### 2. Database setup

`app/database.py`

```python
from sqlalchemy import create_engine
from sqlalchemy.orm import DeclarativeBase, sessionmaker

DATABASE_URL = "sqlite:///./products.db"

engine = create_engine(
    DATABASE_URL,
    connect_args={"check_same_thread": False},
)

SessionLocal = sessionmaker(
    bind=engine,
    autoflush=False,
    autocommit=False,
)


class Base(DeclarativeBase):
    pass


def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

SQLite keeps this example runnable without installing PostgreSQL.

### 3. SQLAlchemy model

`app/models.py`

```python
from sqlalchemy import Float, String
from sqlalchemy.orm import Mapped, mapped_column

from app.database import Base


class Product(Base):
    __tablename__ = "products"

    id: Mapped[int] = mapped_column(primary_key=True)
    name: Mapped[str] = mapped_column(String(100))
    price: Mapped[float] = mapped_column(Float)
```

### 4. Pydantic schemas

`app/schemas.py`

```python
from pydantic import BaseModel, ConfigDict, Field


class ProductCreate(BaseModel):
    name: str = Field(min_length=1, max_length=100)
    price: float = Field(gt=0)


class ProductResponse(BaseModel):
    model_config = ConfigDict(from_attributes=True)

    id: int
    name: str
    price: float
```

`ProductCreate` validates incoming data, while `ProductResponse` defines the shape of the response.

### 5. Business logic

`app/services.py`

```python
from sqlalchemy import select
from sqlalchemy.orm import Session

from app.models import Product
from app.schemas import ProductCreate


def get_products(db: Session) -> list[Product]:
    return list(
        db.scalars(select(Product).order_by(Product.id)).all()
    )


def get_product(db: Session, product_id: int) -> Product | None:
    return db.get(Product, product_id)


def create_product(
    db: Session,
    product_data: ProductCreate,
) -> Product:
    product = Product(**product_data.model_dump())
    db.add(product)
    db.commit()
    db.refresh(product)
    return product
```

### 6. Create the router

`app/routers/products.py`

```python
from fastapi import APIRouter, Depends, HTTPException, status
from sqlalchemy.orm import Session

from app.database import get_db
from app.schemas import ProductCreate, ProductResponse
from app import services

router = APIRouter(
    prefix="/products",
    tags=["Products"],
)


@router.get("/", response_model=list[ProductResponse])
def list_products(db: Session = Depends(get_db)):
    return services.get_products(db)


@router.get("/{product_id}", response_model=ProductResponse)
def get_product(
    product_id: int,
    db: Session = Depends(get_db),
):
    product = services.get_product(db, product_id)

    if product is None:
        raise HTTPException(
            status_code=status.HTTP_404_NOT_FOUND,
            detail="Product not found",
        )

    return product


@router.post(
    "/",
    response_model=ProductResponse,
    status_code=status.HTTP_201_CREATED,
)
def create_product(
    product_data: ProductCreate,
    db: Session = Depends(get_db),
):
    return services.create_product(db, product_data)
```

Notice the imports:

```python
from app.database import get_db
from app.schemas import ProductCreate, ProductResponse
from app import services
```

The router imports the database dependency, Pydantic schemas, and business logic. It doesn't need to know how SQLAlchemy queries or commits are implemented.

### 7. Register the router

`app/main.py`

```python
from contextlib import asynccontextmanager

from fastapi import FastAPI

from app.database import Base, engine
from app.routers.products import router as products_router


@asynccontextmanager
async def lifespan(app: FastAPI):
    Base.metadata.create_all(bind=engine)
    yield


app = FastAPI(
    title="Product API",
    lifespan=lifespan,
)

app.include_router(products_router)


@app.get("/")
def root():
    return {"message": "Hello FastAPI"}
```

The important line is:

```
app.include_router(products_router)
```

This registers all endpoints defined in `products.py` with the main application. The router's `/products` prefix is applied automatically.

### 8. Test the API

Start the server:

```
uvicorn app.main:app --reload
```

Open [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs) to try the endpoints interactively.

| Method | Endpoint      | Expected behavior  |
| ------ | ------------- | ------------------ |
| `GET`  | `/products/`  | List products      |
| `GET`  | `/products/1` | Retrieve product 1 |
| `POST` | `/products/`  | Create a product   |

Example `POST /products/` body:

```
{
  "name": "Coconut",
  "price": 100000
}
```

The API returns `201 Created` with the new product, including its database-generated ID.
