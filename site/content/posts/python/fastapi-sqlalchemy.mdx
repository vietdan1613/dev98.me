FastAPI handles HTTP requests, while SQLAlchemy manages database operations. Together, they provide a simple way to build database-driven APIs using Python.

### 1. Install Dependencies

```bash
pip install fastapi uvicorn "sqlalchemy[asyncio]" asyncpg alembic
```

- **SQLAlchemy:** ORM and database toolkit.
- **asyncpg:** Async PostgreSQL driver.
- **Alembic:** Database schema migrations.

### 2. Configure the Database

Create `app/database.py` to configure the engine, session factory, and database dependency.

```python
from collections.abc import AsyncGenerator

from sqlalchemy.ext.asyncio import (
    AsyncSession,
    async_sessionmaker,
    create_async_engine,
)

DATABASE_URL = "postgresql+asyncpg://user:password@localhost:5432/plant_shop"

engine = create_async_engine(DATABASE_URL)

AsyncSessionLocal = async_sessionmaker(
    engine,
    expire_on_commit=False,
)


async def get_db() -> AsyncGenerator[AsyncSession, None]:
    async with AsyncSessionLocal() as session:
        yield session
```

- **Engine:** Manages database connections.
- **Session factory:** Creates database sessions.
- **`get_db()`:** Provides a session to each request and closes it afterward.

Use environment variables to store database credentials in real applications.

### 3. Define a Database Model

A SQLAlchemy model represents a database table.

```python
from decimal import Decimal

from sqlalchemy import Integer, Numeric, String
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column


class Base(DeclarativeBase):
    pass


class Plant(Base):
    __tablename__ = "plants"

    id: Mapped[int] = mapped_column(primary_key=True)
    name: Mapped[str] = mapped_column(String(100))
    price: Mapped[Decimal] = mapped_column(Numeric(10, 2))
    stock: Mapped[int] = mapped_column(Integer, default=0)
```

Keep SQLAlchemy models separate from Pydantic schemas, which validate request data and define API responses.

### 4. Use the Database in FastAPI

Use `Depends()` to inject a database session into an endpoint.

```python
from fastapi import Depends, FastAPI
from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession

from app.database import get_db
from app.models import Plant

app = FastAPI()


@app.get("/plants")
async def get_plants(
    db: AsyncSession = Depends(get_db),
):
    result = await db.execute(select(Plant))
    return result.scalars().all()
```

To insert a record:

```python
plant = Plant(name="Monstera", price=250000, stock=10)

db.add(plant)
await db.commit()
await db.refresh(plant)
```

Use `await` for asynchronous database operations such as queries and commits. Remember to validate input and define response schemas in production APIs.

### 5. Manage Database Migrations

Use Alembic to track schema changes instead of relying on `create_all()` in production.

```bash
alembic init -t async migrations
alembic revision --autogenerate -m "create plants"
alembic upgrade head
```

Review generated migrations before applying them. Configure Alembic's `target_metadata` to use `Base.metadata`.
