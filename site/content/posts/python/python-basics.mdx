### 1. Variables & Data Types

Python is dynamically typed, meaning you don't need to declare a variable's type. Type hints improve readability and help tools detect errors.

```python
name: str = "Daniel"
age: int = 25
price: float = 99.99
is_active: bool = True
data = None
```

Key points:

- `int`, `float`, `str`, `bool`, `None`
- `type(value)` returns an object's type
- `input()` always returns a string
- Type hints do not enforce types at runtime by themselves
- Python uses `None` to represent the absence of a value

### 2. Operators & Control Flow

Operators perform calculations and comparisons.

| Operator           | Meaning           | Example                |
| ------------------ | ----------------- | ---------------------- |
| `==`               | Equal             | `a == b`               |
| `!=`               | Not equal         | `a != b`               |
| `//`               | Floor division    | `7 // 2 == 3`          |
| `%`                | Modulo            | `7 % 2 == 1`           |
| `**`               | Exponentiation    | `2 ** 3 == 8`          |
| `and`, `or`, `not` | Logical operators | `age >= 18 and active` |

Use `if`, `elif`, and `else` for conditions.

```python
def get_access(age: int, is_active: bool) -> str:
    if age < 18:
        return "Underage"
    elif not is_active:
        return "Account disabled"
    return "Access granted"
```

Loops iterate over collections or repeat while a condition is true.

```python
for number in range(1, 6):
    print(number)

count = 0
while count < 3:
    count += 1
```

- `break`: exits the loop
- `continue`: skips to the next iteration
- `range(start, stop, step)`: excludes `stop`

### 6. Modules & Packages

A module is a Python file. A package organizes related modules, typically in a directory.

Example project structure:

```text
app/
├── main.py
├── routers/
│   └── users.py
├── services/
│   └── user_service.py
└── utils/
    └── math_utils.py
```

Import functions explicitly:

```python
# math_utils.py
def add(a: int, b: int) -> int:
    return a + b
```

```python
# main.py
from utils.math_utils import add

print(add(2, 3))  # 5
```

Key points:

- `import math` imports a module
- `import math as m` creates an alias
- `from module import function` imports a specific name
- Avoid `from module import *` because it makes dependencies less clear
