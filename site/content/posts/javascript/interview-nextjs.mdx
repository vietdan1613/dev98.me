## Sitemap

### 1. What is a sitemap, and how does it help search engines?

A sitemap is an XML file that lists important URLs on a website. It helps search engines discover pages more efficiently and understand when they were last modified.

```ts
import type { MetadataRoute } from 'next'

export default function sitemap(): MetadataRoute.Sitemap {
  return [
    {
      url: 'https://example.com',
      lastModified: new Date(),
    },
    {
      url: 'https://example.com/about',
      lastModified: new Date(),
    },
  ]
}
```

Next.js automatically generates `/sitemap.xml`. However, having a URL in the sitemap does not guarantee indexing.


### 2. How would you handle a sitemap for a large ecommerce website?

I would split URLs into multiple sitemaps, use a sitemap index, fetch data in batches, and cache results to improve performance. I would also include only canonical, indexable URLs.

```text
/sitemap.xml
/sitemap-products-1.xml
/sitemap-products-2.xml
/sitemap-categories.xml
/sitemap-blog.xml
```

For example, a website with 100,000 products could split product URLs across multiple sitemap files, with each containing no more than 50,000 URLs, following Google's sitemap limits.

## Metadata

### 1. What is the difference between `metadata` and `generateMetadata()`?

In Next.js App Router, both are used to define page metadata for SEO.

- `metadata` is used for static metadata when the values are known in advance.
- `generateMetadata()` is used for dynamic metadata when the values depend on route parameters or fetched data.

```ts
// Static metadata
export const metadata: Metadata = {
  title: "My Blog",
  description: "A blog about plants.",
};

// Dynamic metadata
export async function generateMetadata({ params }): Promise<Metadata> {
  const { slug } = await params;
  const post = await getPost(slug);

  return {
    title: post.title,
    description: post.description,
  };
}
```

### 2. How do you implement dynamic metadata for a blog post?

I use `generateMetadata()` in a dynamic route such as `app/blog/[slug]/page.tsx`. I extract the `slug` from `params`, fetch the corresponding blog post, and return its title and description.

```tsx
import type { Metadata } from "next";
import { notFound } from "next/navigation";

type Props = {
  params: Promise<{ slug: string }>;
};

export async function generateMetadata({
  params,
}: Props): Promise<Metadata> {
  const { slug } = await params;
  const post = await getPost(slug);

  if (!post) {
    return { title: "Post Not Found" };
  }

  return {
    title: post.title,
    description: post.description,
    openGraph: {
      title: post.title,
      description: post.description,
      images: [post.image],
      type: "article",
    },
  };
}

export default async function BlogPostPage({ params }: Props) {
  const { slug } = await params;
  const post = await getPost(slug);

  if (!post) notFound();

  return <h1>{post.title}</h1>;
}
```
## JSON-LD

### 1. What is JSON-LD, and how does it help SEO?

JSON-LD (JSON for Linked Data) is a format for adding structured data to a webpage using JSON. It helps search engines understand the page's content and can make it eligible for rich results, such as product information or breadcrumbs.

```json
{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": "Monstera Thai Constellation",
  "description": "A beautiful variegated plant."
}
```

### 2. How do you implement JSON-LD in Next.js App Router?

In Next.js App Router, you can add JSON-LD using a `<script type="application/ld+json">` element inside your page component.

```tsx
export default function ProductPage() {
  const jsonLd = {
    "@context": "https://schema.org",
    "@type": "Product",
    name: "Monstera Thai Constellation",
    description: "A beautiful variegated plant.",
  };

  return (
    <main>
      <script
        type="application/ld+json"
        dangerouslySetInnerHTML={{
          __html: JSON.stringify(jsonLd).replace(/</g, "\\u003c"),
        }}
      />

      <h1>Monstera Thai Constellation</h1>
      <p>A beautiful variegated plant.</p>
    </main>
  );
}
```

Key points:

- Use `JSON.stringify()` to convert the object into JSON.
- Escape `<` to help prevent script injection vulnerabilities.
- Generate structured data dynamically when page content comes from an API.
- Ensure the structured data accurately matches the visible page content.
