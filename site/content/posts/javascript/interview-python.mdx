## Python Fundamentals

### 1. What is Python, and what are its key features?

Python is a versatile, high-level programming language known for its readable syntax and broad range of applications.

- **Simple, readable syntax:** accessible for beginners and efficient for experienced developers.
- **Interpreted:** code runs through the interpreter without a separate compile step, which makes testing and debugging quick.
- **Dynamic typing:** variables don't need explicit type declarations.
- **Extensive libraries and frameworks:** NumPy, pandas, and Django extend Python into data science, web development, and more.
- **Cross-platform:** the same code runs on Windows, macOS, and Linux.

### 2. What is the difference between mutable and immutable data types?

**Mutable** types can be modified after creation. Elements can be added, removed, or changed in place. Examples: `list`, `dict`, `set`. They suit collections that need frequent updates.

```python
a_list = [1, 2, 3]
a_list.append(4)
print(a_list)   [1, 2, 3, 4]

a_dict = {"a": 1, "b": 2}
a_dict["c"] = 3
print(a_dict)   {'a': 1, 'b': 2, 'c': 3}
```

**Immutable** types cannot be modified after creation. Any operation that appears to modify them creates a new object. Examples: `int`, `float`, `str`, `tuple`.

```python
a_str = "hello"
print(a_str.upper())   HELLO (a new string)
print(a_str)           hello (unchanged)

a_tuple = (1, 2, 3)
 a_tuple[0] = 4   TypeError: 'tuple' object does not support item assignment
```

Reassigning a variable, such as `a_num = 20`, does not modify the old object; it binds the name to a different object.

### 3. How do you use the ternary operator in Python?

A ternary operator, or conditional expression, chooses between two values in one line: `value_if_true if condition else value_if_false`.

```python
score = 75

if score < 50:
    grade = "Fail"
elif score < 70:
    grade = "Merit"
else:
    grade = "Distinction"

 Same logic as a nested conditional expression
grade = "Fail" if score < 50 else "Merit" if score < 70 else "Distinction"
print(grade)   Distinction
```

Conditional expressions keep simple assignments compact, but nesting more than one level quickly hurts readability.

### 4. Define a lambda function, an iterator, and a generator.

- A **lambda** is an anonymous function. It can take any number of arguments but contains a single expression, whose value is returned.
- An **iterator** is an object that returns values one at a time through `__next__()` and raises `StopIteration` when exhausted. Calling `iter()` on a list, dict, tuple, or set returns an iterator.
- A **generator** is a function that uses `yield` instead of `return`. Calling it returns an iterator that produces values lazily.

```python
add_ten = lambda a: a + 10
print(add_ten(7))   17

it = iter([1, 2, 3])
print(next(it))   1

def count_up(n):
    for i in range(n):
        yield i

print(list(count_up(3)))   [0, 1, 2]
```

Both are ordered sequences, but they differ in mutability.

| | List | Tuple |
|---|---|---|

### 2. Explain list, dictionary, and tuple comprehensions.

A **list comprehension** builds a new list from an iterable in one line:

```python
my_list = [i for i in range(1, 10)]
 [1, 2, 3, 4, 5, 6, 7, 8, 9]
```

A **dictionary comprehension** uses curly brackets and a `key: value` expression:

```python
my_dict = {i: i**2 for i in range(1, 10)}
 {1: 1, 2: 4, 3: 9, 4: 16, 5: 25, 6: 36, 7: 49, 8: 64, 9: 81}
```

There is **no tuple comprehension**. Parentheses around a comprehension create a generator expression. To get a tuple, pass it to `tuple()`:

```python
my_gen = (i for i in range(1, 10))
 <generator object <genexpr> ...>

my_tuple = tuple(i for i in range(1, 10))
 (1, 2, 3, 4, 5, 6, 7, 8, 9)
```

### 3. What is a `KeyError`, and how do you handle it?

A `KeyError` is raised when you access a dictionary key that doesn't exist. There are three common ways to handle it:

```python
scores = {"alice": 90, "bob": 85}

 1. get() returns None or a default instead of raising
print(scores.get("carol", 0))   0

 2. try/except
try:
    print(scores["carol"])
except KeyError:
    print("Student not found")

 3. Check membership first
if "carol" in scores:
    print(scores["carol"])
```

### 4. What is the difference between a shallow copy and a deep copy?

- A **shallow copy** creates a new outer object but keeps references to the same nested objects. Changing a nested object affects both copies. Create one with `list.copy()`, `[:]`, or `copy.copy()`.
- A **deep copy** recursively copies all nested objects, so the two structures are fully independent. Create one with `copy.deepcopy()`.

```python
import copy

original = [[1, 2], [3, 4]]

shallow = copy.copy(original)
shallow[0].append(99)
print(original)   [[1, 2, 99], [3, 4]]

original = [[1, 2], [3, 4]]
deep = copy.deepcopy(original)
deep[0].append(99)
print(original)   [[1, 2], [3, 4]]
```

Use a shallow copy when the object contains only immutable items or when sharing nested objects is intended. Use a deep copy for nested structures that must be completely independent.


## Functions and OOP

### 1. What is `__init__()`?

`__init__()` is often called the constructor. Python calls it automatically after creating a new instance to initialize the object's state, such as assigning attribute values. Technically, `__new__()` creates the object and `__init__()` initializes it.

```python
class BookShop:
    def __init__(self, title):
        self.title = title

    def book(self):
        print("The title of the book is", self.title)


b = BookShop("Sandman")
b.book()
 The title of the book is Sandman
```

### 2. What are decorators?

A decorator adds behavior to a function or method without modifying its code. It takes a function and returns a wrapper function. Use `functools.wraps` to preserve the original function's name and docstring.

```python
import functools

def my_decorator(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        print("Something is happening before the function is called.")
        result = func(*args, **kwargs)
        print("Something is happening after the function is called.")
        return result
    return wrapper

@my_decorator
def say_hello():
    print("Hello!")

say_hello()
 Something is happening before the function is called.
 Hello!
 Something is happening after the function is called.
```

### 3. What is monkey patching?

Monkey patching changes the behavior of a class or module at runtime by replacing its attributes or methods.

```python
class Monkey:
    def patch(self):
        print("patch() is being called")

def monk_p(self):
    print("monk_p() is being called")

Monkey.patch = monk_p

obj = Monkey()
obj.patch()
 monk_p() is being called
```

Use it sparingly. It is common in tests, but in application code it makes behavior harder to follow.

### 4. What are metaclasses, and how do they differ from regular classes?

A metaclass is the class of a class. Regular classes create objects; metaclasses create classes. By defining a metaclass, you can modify class definitions, enforce rules, or add functionality when a class is created.

```python
class Meta(type):
    def __new__(cls, name, bases, dct):
        print(f"Creating class {name}")
        return super().__new__(cls, name, bases, dct)

class MyClass(metaclass=Meta):
    pass
 Creating class MyClass
```

## Error Handling and Resource Management

### 1. What is the `with` statement designed for?

The `with` statement manages resources. It guarantees cleanup, such as closing a file, even if an exception occurs inside the block. It replaces the manual `try/finally/close()` pattern.

```python
with open("myfile.txt", "w") as file:
    file.write("Hello, Python!")
 The file is closed here
```

### 2. Why use `else` in a `try/except` block?

The `else` block runs only when the `try` block raises no exception. It keeps success logic separate from the code that might fail, so the `except` clauses don't accidentally catch errors from the success path.

```python
try:
    num1 = int(input("Enter Numerator: "))
    num2 = int(input("Enter Denominator: "))
    division = num1 / num2
except (ValueError, ZeroDivisionError):
    print("Invalid input!")
else:
    print(f"Result is: {division}")
    print("Division is successful.")

 Try 1: 2 and d -> Invalid input!
 Try 2: 2 and 1 -> Result is: 2.0, Division is successful.
```

Catch specific exceptions rather than using a bare `except:`, which also catches `KeyboardInterrupt` and hides bugs.

### 3. What are context managers, and how are they implemented?

A context manager ensures a resource is acquired and released properly. A class becomes a context manager by implementing `__enter__()` and `__exit__()`.

```python
class FileManager:
    def __init__(self, filename, mode):
        self.filename = filename
        self.mode = mode

    def __enter__(self):
        self.file = open(self.filename, self.mode)
        return self.file

    def __exit__(self, exc_type, exc_value, traceback):
        self.file.close()

with FileManager("test.txt", "w") as f:
    f.write("Hello, world!")
```

`__exit__()` runs when the block ends, even after an exception, so the file is always closed. The `contextlib.contextmanager` decorator offers a shorter, generator-based alternative.

## Memory and Concurrency

### 1. What is the Global Interpreter Lock (GIL), and why is it important?

The GIL is a mutex in CPython that allows only one thread to execute Python bytecode at a time. It simplifies memory management by protecting internal structures such as reference counts.

- **CPU-bound work:** the GIL prevents true parallelism across threads, so use `multiprocessing` instead.
- **I/O-bound work:** threads still help, because the GIL is released while waiting on network, file, or database operations.

Python 3.13 introduced an experimental free-threaded build without the GIL (PEP 703), and Python 3.14 makes free-threading officially supported. Some C extensions may not yet be compatible.

### 2. How does Python manage memory, and what role does garbage collection play?

Python stores all objects in a private heap managed by the Python memory manager.

- **Reference counting:** each object tracks how many references point to it. When the count drops to zero, the memory is freed immediately.
- **Cyclic garbage collector:** detects and frees groups of objects that reference each other but are no longer reachable.

The `gc` module lets you interact with the collector, for example to trigger a collection with `gc.collect()` or to disable it.

## Algorithms

### 1. What are common searching and graph traversal algorithms?

- **Binary search:** finds an item in a sorted list by repeatedly halving the search range. O(log n).
- **AVL tree:** a self-balancing binary search tree that keeps lookups, insertions, and deletions at O(log n).
- **Breadth-first search (BFS):** explores a graph level by level using a queue. It finds the shortest path in an unweighted graph.
- **Depth-first search (DFS):** explores as far as possible down each branch before backtracking, using recursion or a stack. Useful for maze solving, cycle detection, and tree traversal.
- **A\*:** finds the shortest path using the cost so far plus a heuristic estimate of the remaining cost. Common in maps and games.

```python
from bisect import bisect_left
from collections import deque

def binary_search(nums, target):
    i = bisect_left(nums, target)
    return i if i < len(nums) and nums[i] == target else -1

def bfs(graph, start):
    visited, queue, order = {start}, deque([start]), []
    while queue:
        node = queue.popleft()
        order.append(node)
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)
    return order

graph = {"A": ["B", "C"], "B": ["D"], "C": ["D"], "D": []}
print(binary_search([1, 3, 5, 7], 5))   2
print(bfs(graph, "A"))                  ['A', 'B', 'C', 'D']
```

### 2. How would you implement an LRU cache?

The simplest option is `functools.lru_cache`, which caches a function's results and evicts the least recently used entry once `maxsize` is reached.

```python
from functools import lru_cache

@lru_cache(maxsize=3)
def add(a, b):
    return a + b

print(add(1, 2))   Calculated and cached
print(add(1, 2))   Returned from the cache
```

To build one manually, use `OrderedDict`. Moving a key to the end marks it as recently used, and `popitem(last=False)` removes the oldest. Both operations are O(1).

```python
from collections import OrderedDict

class LRUCache:
    def __init__(self, capacity):
        self.capacity = capacity
        self.cache = OrderedDict()

    def get(self, key):
        if key not in self.cache:
            return None
        self.cache.move_to_end(key)
        return self.cache[key]

    def put(self, key, value):
        self.cache[key] = value
        self.cache.move_to_end(key)
        if len(self.cache) > self.capacity:
            self.cache.popitem(last=False)
```

## Data Science: NumPy and pandas

### 1. What are the advantages of NumPy arrays over Python lists?

- **Memory:** NumPy arrays store elements of one type in a contiguous block, so they use less memory than lists of Python objects. Check with `array.nbytes`.
- **Speed:** operations run in optimized C code, so they are much faster on large arrays.
- **Vectorized operations:** you can add or multiply whole arrays without loops, and NumPy provides many built-in mathematical functions.

```python
import numpy as np

a = np.array([1, 2, 3])
print(a * 2)        [2 4 6]
print([1, 2, 3] * 2)   [1, 2, 3, 1, 2, 3]
```

### 2. What is the difference between `merge()`, `join()`, and `concat()`?

- **`merge()`** combines two DataFrames on one or more columns you specify. It supports `inner` (default), `left`, `right`, `outer`, and `cross` joins.
- **`join()`** combines two DataFrames on their index. It performs a left join by default, and `on` can name a column of the caller to match against the other's index.
- **`concat()`** stacks two or more DataFrames along an axis, rows by default or columns with `axis=1`. It takes a list and needs no key.

```python
pd.merge(df1, df2, how="outer", on="Id")
df1.join(df2)
pd.concat([df1, df2])
```

### 3. How do you identify and deal with missing values?

Use `isnull().sum()` to count missing values per column:

```python
import numpy as np
import pandas as pd

data = {
    "id": [1, 4, np.nan, 9],
    "age": [30, 45, np.nan, np.nan],
    "score": [np.nan, 140, 180, 198],
}

df.isnull().sum()
 id       1
 age      2

```

Then choose a strategy:

- **Drop** rows or columns with `dropna()`. This loses information, so prefer it only for large datasets with few missing values.
- **Fill** with a constant or a statistic using `fillna()`, or carry values with `ffill()` and `bfill()`.
- **Replace** with a sentinel value using `replace()`.
- **Interpolate** values from neighboring data with `interpolate()`.

```python
df.dropna(axis=0, how="any")
df.fillna(df.mean())
df.bfill()
df.replace(to_replace=np.nan, value=-999)
df.interpolate(method="linear", limit_direction="forward")
```

## AI and LLMs

### 1. What is a Large Language Model (LLM), and how do you use one in Python?

An LLM is a deep learning model, usually a transformer, trained on massive text datasets to understand and generate human-like text. Examples include GPT, Claude, Llama, and Gemini. In Python, you call LLMs through a provider's SDK or run open-weight models locally.

```python
from openai import OpenAI

client = OpenAI()   Reads OPENAI_API_KEY from the environment

response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Explain Python decorators in simple terms."},
    ],
)

print(response.choices[0].message.content)
```

Keep API keys in environment variables, not in code.

### 2. What is RAG (Retrieval-Augmented Generation), and why is it important?

RAG combines a retrieval system with an LLM. Instead of relying only on the model's training data, it retrieves relevant documents from a knowledge base and passes them to the LLM as context. This grounds answers in your own, up-to-date data and reduces hallucinations without retraining the model.

Key components:

- **Document store:** a vector database, such as Pinecone, Chroma, or FAISS, holding embedded documents.
- **Retriever:** finds the documents most similar to the query.
- **Generator:** an LLM that writes the answer from the retrieved context.

```python
from langchain_community.vectorstores import Chroma
from langchain_openai import ChatOpenAI, OpenAIEmbeddings

 documents: a list of LangChain Document objects
vectorstore = Chroma.from_documents(documents, OpenAIEmbeddings())
llm = ChatOpenAI(model="gpt-4o-mini")

question = "What are Python best practices?"
docs = vectorstore.similarity_search(question, k=4)
context = "\n\n".join(doc.page_content for doc in docs)

answer = llm.invoke(
    f"Answer using only this context:\n{context}\n\nQuestion: {question}"
)
print(answer.content)
```

### 3. How do you use `async/await` in AI applications?

LLM and API calls spend most of their time waiting on the network. With `asyncio`, one thread can send many requests concurrently, so the total time is close to the slowest request rather than the sum of all of them.

```python
import asyncio
from openai import AsyncOpenAI

client = AsyncOpenAI()

async def get_completion(prompt: str) -> str:
    response = await client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[{"role": "user", "content": prompt}],
    )
    return response.choices[0].message.content

async def process_multiple_prompts(prompts: list[str]) -> list[str]:
    return await asyncio.gather(*(get_completion(p) for p in prompts))

prompts = ["Explain Python lists", "Explain Python dicts", "Explain Python sets"]
for result in asyncio.run(process_multiple_prompts(prompts)):
    print(result)
```

Async helps with I/O-bound work only. For CPU-heavy work, such as running a model locally, use processes or a separate worker.

### 4. What are embeddings, and how are they used?

Embeddings are dense vectors that capture the meaning of data such as text or images. Similar items get vectors that are close together, usually measured with cosine similarity. They power semantic search, clustering, recommendations, and the retrieval step in RAG.

```python
import numpy as np
from sentence_transformers import SentenceTransformer

model = SentenceTransformer("all-MiniLM-L6-v2")

sentences = [
    "Python is a programming language",
    "JavaScript is used for web development",
    "Python is great for data science",
]
embeddings = model.encode(sentences)

def cosine_similarity(a, b):
    return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))

print(f"0-2: {cosine_similarity(embeddings[0], embeddings[2]):.3f}")   Higher
print(f"0-1: {cosine_similarity(embeddings[0], embeddings[1]):.3f}")   Lower
```

### 5. How would you build an AI agent in Python?

An AI agent uses an LLM to decide which actions to take to reach a goal. Its key components are:

- **LLM core:** the reasoning engine that reads the input and decides the next step.
- **Tools:** functions the agent can call, such as web search, database queries, APIs, or code execution.
- **Memory:** short-term conversation history and long-term knowledge, often in a vector store.
- **Planning:** breaking complex tasks into smaller steps.

The core is a loop: the LLM picks a tool call, the application runs it, and the result goes back to the LLM until it can answer. Frameworks such as LangChain provide this loop:

```python
from langchain.agents import create_agent

def search_database(query: str) -> str:
    """Search the company database for information."""
    return f"Results for: {query}"

agent = create_agent(
    model="openai:gpt-4o-mini",
    tools=[search_database],
    system_prompt="You are a helpful data assistant.",
)

result = agent.invoke(
    {"messages": [{"role": "user", "content": "Find sales data for Q4"}]}
)
print(result["messages"][-1].content)
```

In production, add guardrails such as a maximum number of steps, validation of tool arguments, and logging.

### 2. Can a string be split into dictionary words?

Given a string and a dictionary of words, determine whether the string can be segmented into dictionary words.

Try every prefix `s[:i]`. If the prefix is a dictionary word, recursively check whether the rest `s[i:]` can also be segmented. Memoization stores results for substrings already checked, which avoids exponential work on long strings.

```python
def can_segment_str(s, dictionary, memo=None):
    if memo is None:
        memo = {}
    if s in memo:
        return memo[s]
    if not s:
        return True

    for i in range(1, len(s) + 1):
        if s[:i] in dictionary and can_segment_str(s[i:], dictionary, memo):
            memo[s] = True
            return True

    memo[s] = False
    return False

print(can_segment_str("datacamp", {"data", "camp", "cam", "lack"}))   True
print(can_segment_str("datacamx", {"data", "camp", "cam", "lack"}))   False
```

Using a set for the dictionary makes each lookup O(1).

### 3. Check whether a string is a palindrome.

A palindrome reads the same forward and backward. Keep only letters and digits, lowercase them, and compare the string with its reverse.

```python
def is_palindrome(s):
    s = "".join(ch for ch in s if ch.isalnum()).lower()
    return s == s[::-1]

print(is_palindrome("A man, a plan, a canal: Panama"))   True
print(is_palindrome("hello"))                            False
```

## Coding: Numbers and Math

### 1. Return `True` if a positive integer is a perfect square.

Take the exact integer square root with `math.isqrt()`, square it, and compare it with the original number. This avoids floating-point rounding errors from `math.sqrt()`.

- `10`: the integer square root is `3`, and `3 * 3 = 9`, so `False`.
- `36`: the integer square root is `6`, and `6 * 6 = 36`, so `True`.

```python
import math

def valid_square(num):
    if num < 0:
        return False
    root = math.isqrt(num)
    return root * root == num

print(valid_square(10))   False
print(valid_square(36))   True
```

### 2. Count the trailing zeros in `n!`.

Count only the **trailing** zeros, not all zeros. For example, `7! = 5040` has two zeros but only one trailing zero.

The direct approach computes the factorial, then counts zeros from the end of its string form:

```python
import math

def factorial_trailing_zeros(n):
    digits = str(math.factorial(n))
    return len(digits) - len(digits.rstrip("0"))

print(factorial_trailing_zeros(7))    1
print(factorial_trailing_zeros(10))   2
print(factorial_trailing_zeros(18))   3
```

Factorials grow very quickly, so the better solution counts factors of 5. Each trailing zero comes from a factor of 10 (2 × 5), and there are always more 2s than 5s. This runs in O(log n):

```python
def trailing_zeros(n):
    count = 0
    while n >= 5:
        n //= 5
        count += n
    return count

print(trailing_zeros(18))    3
print(trailing_zeros(100))   24
```

### 3. Find the missing number in a list of `1` to `n`.

All numbers from `1` to `n` are present except one. Since one is missing, `n` is the list length plus one. Calculate the expected sum with `n * (n + 1) // 2` and subtract the actual sum.

```python
def find_missing(nums):
    n = len(nums) + 1
    expected_sum = n * (n + 1) // 2
    return expected_sum - sum(nums)

print(find_missing([4, 5, 3, 2, 8, 1, 6]))   7
print(find_missing([1, 5, 6, 3, 4]))         2
```

This is O(n) time and O(1) space.

### 4. How many ways can you make change for an amount?

Given coin denominations and a total amount, return the number of ways to make the amount.

Use dynamic programming. `solution[i]` holds the number of ways to make amount `i`, and `solution[0] = 1` because there is one way to make zero: use no coins. For each coin, update every amount from the coin's value upward with `solution[i] += solution[i - coin]`. Looping over coins in the outer loop counts combinations, not orderings.

```python
def solve_coin_change(denominations, amount):
    solution = [0] * (amount + 1)
    solution[0] = 1
    for coin in denominations:
        for i in range(coin, amount + 1):
            solution[i] += solution[i - coin]
    return solution[amount]

print(solve_coin_change([1, 2, 5], 5))   4
```

This is O(amount × number of coins) time and O(amount) space.

## Coding: Arrays

### 1. Remove duplicates from a sorted array in place.

Given a sorted array, keep each unique element once in the first `k` positions and return `k`. Elements after index `k` don't matter.

Walk the array from index 1. Whenever the current element differs from the previous one, write it at `insert_index` and advance `insert_index`.

```python
def remove_duplicates(array):
    if not array:
        return 0
    insert_index = 1
    for i in range(1, len(array)):
        if array[i - 1] != array[i]:
            array[insert_index] = array[i]
            insert_index += 1
    return insert_index

array_1 = [1, 2, 2, 3, 3, 4]
k1 = remove_duplicates(array_1)
print(k1, array_1[:k1])   4 [1, 2, 3, 4]

array_2 = [1, 1, 3, 4, 5, 6, 6]
k2 = remove_duplicates(array_2)
print(k2, array_2[:k2])   5 [1, 3, 4, 5, 6]
```

This is O(n) time and O(1) space.

### 2. Find the maximum single-sell profit.

Given stock prices, return the buy and sell prices for the highest profit from one buy and one later sell. If no profit is possible, return the trade with the smallest loss.

Make one pass while tracking the lowest buy price so far and the best profit. For each price, compute the profit of selling there; if it beats the best, record this price as the sell price. Then update the lowest buy price. Starting the best profit at the difference between the first two prices ensures a falling market still returns the smallest loss.

```python
def buy_sell_stock_prices(prices):
    current_buy = prices[0]
    global_sell = prices[1]
    global_profit = global_sell - current_buy

    for i in range(1, len(prices)):
        current_profit = prices[i] - current_buy

        if current_profit > global_profit:
            global_profit = current_profit
            global_sell = prices[i]

        if current_buy > prices[i]:
            current_buy = prices[i]

    return global_sell - global_profit, global_sell

print(buy_sell_stock_prices([8, 4, 12, 9, 20, 1]))    (4, 20)
print(buy_sell_stock_prices([10, 9, 16, 17, 19, 23]))   (9, 23)
print(buy_sell_stock_prices([8, 6, 5, 4, 3, 2, 1]))   (6, 5)
```

This is O(n) time and O(1) space.

### 3. Find a Pythagorean triplet in an array.

Return `True` if the array contains `a`, `b`, and `c` with a² + b² = c².

Square every element and sort the squares. For each candidate c², starting from the largest, scan the smaller squares while keeping a set of values seen. If c² − b² is already in the set, a triplet exists.

```python
def check_triplet(nums):
    squares = sorted(x * x for x in nums)

    for i in range(len(squares) - 1, 1, -1):
        seen = set()
        for j in range(i - 1, -1, -1):
            if squares[i] - squares[j] in seen:
                return True
            seen.add(squares[j])
    return False

print(check_triplet([3, 1, 4, 6, 5]))     True
print(check_triplet([10, 4, 6, 12, 5]))   False
```

This is O(n²) time and O(n) space, and it doesn't modify the input list.

### 4. Find the maximum `j - i` such that `arr[j] > arr[i]`.

- `[20, 70, 40, 50, 12, 38, 98]` returns `6` (`i = 0`, `j = 6`).
- `[10, 3, 2, 4, 5, 6, 7, 8, 18, 0]` returns `8` (`i = 0`, `j = 8`).

The brute-force solution checks each `i` from the left and scans `j` from the right, stopping at the first `arr[j] > arr[i]` because that gives the largest gap for this `i`. This is O(n²).

```python
def max_index_diff(arr):
    n = len(arr)
    max_diff = -1
    for i in range(n):
        for j in range(n - 1, i, -1):
            if arr[j] > arr[i]:
                max_diff = max(max_diff, j - i)
                break
    return max_diff

print(max_index_diff([20, 70, 40, 50, 12, 38, 98]))          6
print(max_index_diff([10, 3, 2, 4, 5, 6, 7, 8, 18, 0]))      8
```

For O(n), build a prefix-minimum array and a suffix-maximum array, then walk them with two pointers:

```python
def max_index_diff_linear(arr):
    n = len(arr)
    left_min = [arr[0]] * n
    for i in range(1, n):
        left_min[i] = min(left_min[i - 1], arr[i])

    right_max = [arr[-1]] * n
    for j in range(n - 2, -1, -1):
        right_max[j] = max(right_max[j + 1], arr[j])

    i = j = 0
    max_diff = -1
    while i < n and j < n:
        if left_min[i] < right_max[j]:
            max_diff = max(max_diff, j - i)
            j += 1
        else:
            i += 1
    return max_diff

print(max_index_diff_linear([20, 70, 40, 50, 12, 38, 98]))   6
```
